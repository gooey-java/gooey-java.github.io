Get started in three sips

  1. Grab the jar

    Download both .jar files from the library’s card on this page.

  2. Drop it in lib

    Put both jars in your project’s lib folder. VS Code picks them up automatically and shows the docs when you hover over GooeyGUI code.

  3. Import and run

    Add the import at the top of your file, write your code and hit Run.

// The first line of every GooeyGUI program
import gooeygui.*;
